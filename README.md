# PROJECT: UNDERCITY

Juego 3D jugable construido con React, TypeScript, Vite, Three.js y React Three Fiber.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

El workflow de GitHub Actions despliega automáticamente `dist` a GitHub Pages desde `main`.

## Controles

- `WASD` o flechas: mover
- `E`: entrar al vehículo
- `Q`: salir del vehículo
